┌─────────────────────────────────────────────────────────────────────────────┐
│ RÈGLES DE MAPPING BSA (PDF → Excel)                                         │
└─────────────────────────────────────────────────────────────────────────────┘

  Colonne Excel              Source PDF BSA          Type
  ─────────────────────────────────────────────────────────────────────────
  Montant_Reclame_Brut    =  FR.REELS               Montant (Ar)
  Ticket_Moderateur       =  Tx (%)                 Pourcentage (%)
  Montant_Paye_Regle      =  REMB                   Montant (Ar)
  Montant_Exclu_Rejet     =  FR.REELS - REMB        LE RESTE (= 0 si FR.REELS = REMB)

  Note : Dans le PDF BSA, NON_REMB inclut le TPG.
         NON_REMB - TPG sert de CONTRÔLE CROISÉ : cette valeur doit être
         égale au reste (FR.REELS - REMB), sinon INCOHÉRENCE signalée.


┌─────────────────────────────────────────────────────────────────────────────┐
│ VÉRIFICATION DE COHÉRENCE                                                    │
└─────────────────────────────────────────────────────────────────────────────┘

  RÈGLE BSA (la règle du reste) :

             SI FR.REELS = REMB  ALORS  LE RESTE = 0

  Le reste (Montant_Exclu_Rejet) = FR.REELS - REMB.
  Contrôle croisé : le reste doit être égal à NON_REMB - TPG.

  Formule :  FR.REELS = REMB + (NON_REMB - TPG)

  Ou en termes Excel :
             Montant_Reclame_Brut = Montant_Paye_Regle + Montant_Exclu_Rejet

  ✅ Résultat : 51 lignes vérifiées, 0 incohérence détectée
  ✅ 43 lignes avec FR.REELS = REMB → toutes avec reste = 0 (43/43)
  ✅ Totaux : 888 500 = 777 650 (REMB) + 110 850 (reste)
